## 📂 Estructura del Directorio

El proyecto está organizado de manera secuencial dentro del directorio `basic`, diseñado para avanzar progresivamente en la dificultad. Por cada tema encontrarás archivos de teoría, ejercicios propuestos y **mis propias implementaciones** para resolverlos:

### 🗺️ Índice de Contenidos

* **`c00_helloworld/` - Primeros Pasos**
  * Introducción a la sintaxis de Java, la máquina virtual (JVM) y el clásico `HelloWorld.java`.

* **`c01_beginner/` - Variables y Tipos de Datos**
  * Manejo de tipos de datos primitivos (`DataTypes.java`) y declaración de variables y constantes.

* **`c02_operators/` - Operadores**
  * Operadores aritméticos, de asignación, lógicos, de comparación y unarios.

* **`c03_strings/` - Cadenas de Texto**
  * Manipulación de texto usando los métodos de la clase String (`length`, `substring`, `equals`, `format`, etc.).

* **`c04_conditionals/` - Condicionales**
  * Control del flujo del programa utilizando sentencias `if`, `else if`, `else` y `switch`.

* **`c05_structures/` - Estructuras de Datos**
  * Colecciones y agrupaciones de datos: Arreglos estáticos (`Arrays.java`), Listas dinámicas (`Lists.java`), Conjuntos sin duplicados (`Sets.java`) y Diccionarios clave-valor (`Maps.java`).

* **`c06_loops/` - Bucles e Iteraciones**
  * Automatización y repetición de tareas con `for`, `forEach`, `while` y `do while`.

* **`c07_functions/` - Funciones**
  * Creación de código reutilizable mediante la declaración de métodos, uso de parámetros y retornos.

* **`c08_oop/` y `c08_test_oop/` - Programación Orientada a Objetos (POO)**
  * El núcleo del paradigma: Clases y Objetos (`Classes.java`, `Person.java`), Abstracción, Herencia, Polimorfismo y Composición.
  * También incluye pruebas de encapsulamiento y Modificadores de Acceso.

* **`c09_exceptions/` - Manejo de Excepciones**
  * Gestión de errores en tiempo de ejecución: uso de `try-catch` (`Exceptions.java`), propagación (`ThrowExample.java`) y creación de excepciones propias (`CustomException.java`).

* **`c10_extras/` - Conceptos Extra**
  * Funcionalidades, características adicionales del lenguaje y retos finales.

## 🚀 Cómo utilizar este repositorio

Si quieres revisar mi código o probar las soluciones tú mismo, solo necesitas tener el [JDK de Java](https://www.oracle.com/es/java/technologies/downloads/) instalado en tu equipo.

1. Clona este repositorio:
```bash
   git clone [https://github.com/TU_USUARIO/TU_REPOSITORIO.git](https://github.com/TU_USUARIO/TU_REPOSITORIO.git)
```

Ábrelo con tu IDE favorito (recomiendo IntelliJ IDEA, Eclipse o VS Code).

Navega hasta el paquete que te interese dentro de basic/.

Ejecuta los archivos .java directamente desde el IDE para ver la salida en la consola.
